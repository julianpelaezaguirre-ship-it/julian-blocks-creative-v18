# Julian Blocks V11

## Dos modos de juego

Al abrir el juego puedes elegir:

### Modo normal
Mantiene Julian Blocks: construcción, mundo por chunks, biomas, aldeas, cuevas, energía, portales, dimensión de Brasas, clima, mapa, mobs e inventario creativo.

### Modo Dinosaurios
Es una experiencia original inspirada en mods paleontológicos de Minecraft. No contiene código, modelos ni texturas de Jurassic Reborn.

Incluye:
- Dinosaurios propios de Julian Blocks.
- Rocas fósiles.
- Analizador de ADN.
- Incubadora.
- Progresión fósil -> ADN -> huevo -> dinosaurio.
- Dinosaurios carnívoros y herbívoros con comportamientos diferentes.
- Huevos de dinosaurio en el inventario creativo.
- Más dinosaurios generándose al explorar.

## Cómo usar el laboratorio

1. Escoge MODO DINOSAURIOS.
2. Busca y rompe una Roca fósil.
3. Haz clic derecho sobre el Analizador de ADN cerca del inicio.
4. Cada fósil procesado suma 25% de ADN.
5. Con 100% de ADN usa la Incubadora.
6. Crea un huevo y luego hazlo eclosionar.

## Controles

- W A S D: moverte
- Mouse: mirar
- Espacio: subir
- Shift: bajar
- F: turbo
- E: inventario
- C: crafteo
- M: criaturas
- TAB: mapa
- T: clima
- K: guardar
- L: cargar
- Clic izquierdo: romper / atacar
- Clic derecho: colocar / interactuar
