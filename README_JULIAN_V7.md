# Julian Blocks V7

## Mejoras principales

- Mobs reconstruidos con más piezas y siluetas diferentes.
- Ojos, hocicos, orejas, cuernos, colas, alas y detalles por especie.
- Animación de patas al caminar, alas al volar y pequeños movimientos de cabeza/cola.
- Los enemigos tienen rasgos visuales más fáciles de distinguir.
- Se mantiene la IA de estados, aldeas, chunks, biomas, mapa e inventario de V6.
- Hay contenido secreto que no se explica aquí: hay que encontrarlo jugando.

## Ejecutar

```powershell
npm install
npm run dev
```
