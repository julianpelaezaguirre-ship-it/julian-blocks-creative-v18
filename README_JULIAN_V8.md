# Julian Blocks V8

## Qué se mejoró

- Cuevas y subsuelo más profundo con vetas de minerales.
- Clima dinámico: despejado, lluvia y tormenta. Pulsa T para cambiarlo manualmente.
- Partículas al romper, colocar y golpear.
- Sonidos procedurales sin archivos externos.
- Cofres generados en casas y aldeas.
- Aldeanos interactivos: clic derecho para abrir intercambios creativos.
- Se mantiene el mundo por chunks, biomas, estructuras, minimapa, mobs, IA, inventario, crafteo, guardado y Tierras Lejanas.

## Controles
WASD mover · Espacio subir · Shift bajar · F turbo · T clima · E inventario · C crafteo · M criaturas · Tab mapa · K guardar · L cargar.

## Para ejecutar
```
npm install
npm run dev
```
