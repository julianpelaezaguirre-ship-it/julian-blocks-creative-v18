# Julian Blocks V17

Esta V17 está construida sobre la V16 correcta.

## Cambios principales

- Los mobs y NPCs tienen más detalles visuales.
- Los NPCs especializados tienen calzado, cinturones, cascos, mochilas, gafas y accesorios según su profesión.
- Los dinosaurios carnívoros tienen dientes y detalles adicionales.
- Al cambiar entre Normal, Dinosaurios y Marvel Zombies se eliminan todos los mobs/NPCs del modo anterior.
- Se limpian también los registros de NPCs y cautivos antes de generar el nuevo ecosistema.
- Las aldeas generan equipos de NPCs distintos según el modo.
- Las estructuras principales tienen entradas monumentales, caminos, balizas y luces.
- Las casas tienen porche, chimenea y vegetación.
- Se conservan los calabozos subterráneos de V16, dinosaurios rescatables, lobos domesticables y zombis curables.

## Ejecutar

npm install
npm run dev
