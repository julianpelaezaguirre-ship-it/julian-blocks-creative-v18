# Julian Blocks V14

## Novedad principal: estructuras al 75%

En el Mundo Verde, cada chunk elegible tiene un 75% de probabilidad de recibir una estructura compacta. El tipo cambia según el modo:

- Normal: torres radar, búnkeres, laboratorios, refugios, puestos paleontológicos, estaciones de exploradores y cuarentena.
- Dinosaurios: más laboratorios genéticos y puestos paleontológicos, además de las demás estructuras.
- Marvel Zombies: más búnkeres, radares, refugios y puestos de cuarentena.

También siguen existiendo aldeas gigantes y estructuras secretas raras.

## Nuevos bloques V14

- Cerca eléctrica (`electricFence`): repele y daña amenazas que se acercan.
- Muro reforzado (`reinforcedWall`): requiere una herramienta fuerte para romperse.
- Radar Mini-IA (`radarArray`): clic derecho para contar señales biológicas y amenazas en 64 bloques.
- Escáner biológico (`bioScanner`): clic derecho para identificar la criatura más cercana y su vida.
- Analizador de ADN (`dnaAnalyzer`).
- Incubadora (`incubator`).
- Caja paleontológica (`dinoCrate`).
- Roca fósil (`fossilRock`).
- Cristal antizombies (`antiZombieGlass`): defensa que empuja amenazas cercanas.
- Placa de acero (`steelPlate`).
- Bloque de seguridad (`hazardStripe`).
- Luz de escáner (`scannerLight`).
- Ladrillo fósil (`fossilBrick`).
- Estación médica (`medicalStation`): clic derecho para restaurar la vida.
- Caja de suministros (`ammoCrate`).
- Baliza de vigilancia (`watchBeacon`): informa de estructuras cercanas.

Todos los bloques aparecen en el inventario creativo con `E`.

## Nuevas herramientas

- Llave de ingeniería
- Escáner portátil: clic derecho apuntando a una criatura para ver sus datos.
- Bastón eléctrico
- Brocha paleontológica: en Modo Dinosaurios obtiene más fósiles al romper Roca Fósil.
- Pico reforzado
- Martillo de rescate

## Estructuras nuevas

- Torre Radar Mini-IA con Escáner Biológico y Cerca Eléctrica.
- Búnker blindado con Muro Reforzado y Cristal Antizombies.
- Laboratorio de Genética con Analizador de ADN, Incubadora y Caja Paleontológica.
- Refugio avanzado con Lámparas de Potencia y Mesa de Crafteo.
- Puesto paleontológico rodeado de rocas fósiles.
- Puesto de cuarentena.
- Estación de exploradores.

Las estructuras se muestran en el minimapa como cuadrados de colores.

## Controles

- WASD: mover
- Espacio / Shift: subir / bajar
- E: inventario
- C: crafteo
- M: criaturas
- Tab: mapa
- T: clima
- K: guardar
- L: cargar
- Clic izquierdo: romper / atacar
- Clic derecho: colocar / usar / interactuar

## Ejecutar

```powershell
npm install
npm run dev
```
